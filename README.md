PrésenceManager

Description du projet

PrésenceManager est une application Android destinée à faciliter la gestion des présences des stagiaires au sein d’un établissement de formation.

L’application permettra progressivement aux formateurs de sélectionner un groupe, consulter la liste des stagiaires, enregistrer les présences et les absences, et visualiser un récapitulatif.

Technologies utilisées

* XML
* Android Studio
